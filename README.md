# steermask

Steer encode/decode helpers for mask payloads in pipelines.

**Site:** https://theworker02.github.io/steermask/

## Install / run

```bash
git clone https://github.com/theworker02/steermask.git
cd steermask
node src/cli.js
node --test
```
